# Personal Website

A clean, responsive personal portfolio built with vanilla HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — theme toggle, reveal animations and small interactions

## Customize
Edit the text in `index.html` to add your own bio, projects and social links.

## GitHub Pages
In the repository settings, open **Pages** and choose **Deploy from a branch**, then select `main` and `/(root)`.
